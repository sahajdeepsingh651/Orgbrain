# Orgbrain — Decision Log

> Standing rule for this project: every architectural or design decision, and the reasoning behind it, gets recorded here (or in the most relevant doc) as it's made — not reconstructed later from memory.

| 2026-08-09 | **MCP is READ-ONLY.** `search_knowledge` / `get_agent_activity` / `handoff` only. All AI-session-originated WRITES go AI session → Interceptor → Context Bus. `record_insight` is not built and must not be. | An MCP server is not in the payload path — the harness executes tool calls locally and they never reach the model API — so it can never see the `tool_result` block where a credential actually lands. Half the problem statement ("stop confidential data leaving through AI prompts") therefore cannot be built on it, and a second write path would bypass both the DLP boundary and the human approval gate. Reads are ingress, not egress, so the rule does not extend to them. | Banning MCP entirely (rejected — over-applies an egress rule to ingress, and gives up the surfaces the gateway structurally cannot reach: claude.ai, Claude Desktop). Routing MCP through the interceptor to make the invariant structural rather than by-omission (deferred — coherent but net-new surface). **Accepted cost: MCP reads bypass the interceptor's audit log.** Partial mitigation: an MCP tool result re-enters as a `tool_result` on the next request, which does pass the gateway's DLP. |
| 2026-08-09 | Scoped the interceptor invariant to **AI-session-originated** traffic. Non-AI connectors (Jira/Confluence batch ingestion) are direct Context Bus clients with their own connector identity. | Stated without the qualifier, "all traffic to the bus goes through the Interceptor" would force a batch document connector through an LLM proxy, which is absurd. The interceptor exists to police what AI sessions send, not to be a universal ingest gateway. | Literal all-traffic invariant (rejected — see above). |
